# 프로젝트 소개
* 강의주차: 5주차 3교시 e-동창회 웹사이트 만들기 - 수정본(워드프레스의 초대장 템플릿 중 적합한 디자인 적용하기)
* 기능
  - 추억의 사진 슬라이드(페이드 인/아웃 전환)
  - 동창회 날짜 안내
  - 동창회 까지 남은 일/시간 안내
  - 위치 지도 안내
  - 공유 버튼 제공
